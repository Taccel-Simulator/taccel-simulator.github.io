VBTS Config¶

The Vision-Based Tactile Sensor (VBTS) stores configures necessary to integrate them on robots within the simulation.

class taccel.turdf.sensor.SensorElastomer(name: str = '', tet_mesh: UnstructuredGrid | None = None, vertex_labels: ndarray | None = None, marker_bc_idxs: ndarray | None = None, marker_bc_coords: ndarray | None = None, source_mesh_md5: str | None = None)¶

Bases: object

Manages a tetrahedral mesh with custom data attributes for tactile sensors.

This class encapsulates a pyvista.UnstructuredGrid tetrahedral mesh, vertex labels, and optional marker points. It provides methods for I/O to binary VTK files and for computing derived properties like surface meshes, labeled sub-parts, and marker coordinates. This class does not contain any URDF-specific or sensor-related logic.
